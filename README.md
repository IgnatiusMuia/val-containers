# Val Containers

Marketing and catalogue site for Val Containers, a Nairobi-based shipping container dealer.

## Stack

- Next.js 16 (App Router, Cache Components)
- React 19
- Tailwind CSS 4
- TypeScript

## Local development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Scripts

```bash
npm run dev    # development server
npm run lint   # ESLint
npm run build  # production build
npm run start  # production server
```

## Environment

Set `NEXT_PUBLIC_SITE_URL` to the deployed origin in production so canonical URLs, Open Graph metadata and the sitemap use the correct domain.

```bash
NEXT_PUBLIC_SITE_URL=https://valcontainers.co.ke
```
